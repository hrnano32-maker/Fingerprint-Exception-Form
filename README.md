# Fingerprint Exception Form

หน้าเว็บแจ้งกรณีสแกนนิ้วไม่ติดสำหรับพนักงาน

- รหัสพนักงานและชื่อจับคู่อัตโนมัติ
- รองรับมือถือ
- เลือกประเภทเข้างาน/เลิกงาน
- แนบรูปจากมือถือ

หมายเหตุ: เวอร์ชันหน้าเว็บนี้เก็บรายการชั่วคราวในเครื่องผู้ใช้เพื่อให้หน้า GitHub Pages ทำงานได้โดยไม่พึ่ง Apps Script. Backend กลางสำหรับเก็บรูปและรายการจะเชื่อมแยกต่างหากก่อนใช้งานจริงเต็มรูปแบบ.
